教程文档

选择通知渠道后，在 设置 → 通知渠道 中填写对应配置即可。以下为各渠道的接入教程与官方文档。

🛰️ Telegram

官方文档
  1. 在 Telegram 中搜索 @BotFather，发送 /newbot 创建机器人。
  2. 复制 Bot Token 填入设置页。
  3. 给机器人发一条消息，然后访问 https://api.telegram.org/bot<TOKEN>/getUpdates 获取 Chat ID。

📌 钉钉

官方文档
  1. 打开钉钉群 → 群设置 → 智能群助手 → 添加机器人 → 自定义。
  2. 安全设置可选择「加签」，将生成的密钥填入 Secret。
  3. 复制 Webhook 地址填入设置页。

💼 企业微信

官方文档
  1. 在企业微信群中添加「群机器人」。
  2. 复制机器人 Webhook 地址。
  3. 粘贴到设置页 Webhook 输入框并保存。

🕊️ 飞书

官方文档
  1. 在飞书群中添加「群机器人」→「自定义机器人」。
  2. 复制 Webhook 地址。
  3. 粘贴到设置页 Webhook 输入框并保存。

🍟 Server酱

官方文档
  1. 打开 Server酱 Turbo 官网，使用微信扫码登录。
  2. 在「SendKey」页面复制你的 SendKey。
  3. 填入设置页并保存。

➕ PushPlus

官方文档
  1. 打开 PushPlus 官网，微信扫码登录。
  2. 复制个人 Token。
  3. 如需指定群组，可填写群组编码 Topic（可选）。

🍎 Bark

官方文档
  1. 在 iOS 设备安装 Bark，复制应用内 Key。
  2. 默认使用官方服务器；自建服务器则填写服务器地址。
  3. 填入设置页并保存。

🤖 QQ 机器人（官方 API）

QQ 官方文档

接入 QQ 官方机器人 API v2，自动获取 access_token 并发送主动消息。点击下方「展开完整教程」查看详细步骤与 openid 获取方法。

  1. 前往 QQ 开放平台创建机器人应用，获取 BotAppID 与 AppSecret。
  2. 在设置页「通知渠道 → QQ」填写 BotAppID、AppSecret。
  3. 选择「C2C 私聊 / 群聊 openid」，把接收对象 openid 填入。
  4. 点「测试消息」即可验证是否发送成功。

🔔 ntfy

官方文档
  1. 使用官方服务或自建 ntfy 服务器。
  2. 自定义一个 Topic 名称。
  3. 如服务开启了鉴权，填写 Token（可选）。

📬 Gotify

官方文档
  1. 部署 Gotify 服务器。
  2. 创建应用并复制应用 Token。
  3. 填写服务器地址与 Token 并保存。

🔗 自定义 Webhook

查看请求格式
  1. 填写你自己的 Webhook URL。
  2. 本服务会以 POST 提交 JSON。
  3. 请求体格式见下方说明。

自定义 Webhook 请求体格式

收到通知时，会向目标 URL 发送如下 JSON：

{
  "title": "标题",
  "content": "内容",
  "text": "标题\n内容"
}

🤖 QQ 机器人（官方 API）完整教程

1️⃣ 创建应用并获取凭证

前往 QQ 开放平台 创建机器人应用，获取 BotAppID 与 AppSecret，并开通「主动消息」相关权限。

2️⃣ 在后台填写配置
  1. 在设置页「通知渠道 → QQ机器人」填写 BotAppID、AppSecret。
  2. 私聊选「C2C 私聊 openid」，群聊选「群聊 openid」。
  3. 把对应 openid 填入「接收对象 openid」，点击「测试消息」验证。
📎 openid 是什么？

openid 是平台针对「某个用户/群 × 某款机器人」生成的随机字符串（带中横线，例如 xxxx-xxxx-xxxx），不是QQ 号或群号。不同机器人下，同一个用户的 openid 不同。

🛠 方式一：用官方「获取 openid」调试工具
  1. 登录 QQ 开放平台 → 进入你的机器人应用。
  2. 找到「调试信息 / 获取 openid / 开放调试」等入口（入口位置随官方改版变化）。
  3. 按提示输入目标用户的 QQ（或目标群号），返回该用户/群在该应用下的 openid。
  4. 复制 openid 粘贴到设置页。
🧩 方式二：从事件回调中抓取 openid

最稳妥：先让目标用户（私聊）给机器人发一条消息，或把机器人拉进目标群并发一句话，再抓取事件内容中的 openid。

// C2C 私聊消息事件（找 author.openid）
{
  "author":  { "openid": "用户在该机器人下的 openid" },
  "message": { "content": "触发一条私聊" }
}
// 群聊消息事件（找 中中的 group_openid 字段）
{
  "author":       { "openid": "用户 openid" },
  "group_openid": "群机器人所在的 openid"
}
一句话：私聊填 author.openid，群聊填 group_openid。

C2C 私聊填 author.openid；群聊填 group_openid，二者不可互换。

⚠️ 主动消息限制

官方主动消息要求用户/群与机器人曾有过互动，同时受频次与配额限制；若收不到请按官方平台权限与配额调整。
