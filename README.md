# 7MA用车助手（uni-app 壳工程）

用途：把网页版 7MA 用车助手对接到安卓 App（APK），实现快捷用车，用 WebView 加载你配置的平台地址下的 `/app`。

## 使用步骤（HBuilderX 3.3.5）

1. 打开 `HBuilderX`
2. 菜单：文件 → 打开目录 → 选择本目录（`pack\uni-app-7ma`）
3. 修改根目录 `config.js`：
   ```js
   export default { baseUrl: 'http://192.168.11.162:4321' }  // 本机IP地址；
   ```
4. 预览调试（不打包先看效果）：
   - 菜单：运行 → 运行到浏览器 → Chrome/手机浏览器模拟器
   - 或：运行 → 运行到手机或模拟器（需 USB 连接安卓手机并开启开发者调试）
5. 打包 APK：
   - 菜单：发行 → 原生App-云打包
   - 选择 Android，勾选「公共测试证书」（无自有证书时）
   - 登录 DCloud 账号后点击打包，完成下载 apk 安装到手机

## 注意事项

- 壳内的扫码功能依赖平台地址是 **HTTPS**（安卓 WebView 对 http 明文有限制）；若你的 7MA 平台只有 http，扫码可能不可用，可用「相册/拍照」和「手动输入」兜底。
- 打包前记得在 `config.js` 把 `baseUrl` 改成你的实际地址；以后换地址改这里重新打包即可。
- web-view 页面内仍由配套 App 自身管理“服务地址 + API 密钥”（首次打开填写，左上角齿轮修改）。
