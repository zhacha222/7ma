Features

核心功能

从下单到还车全程自动化，后台集中管理多账号与积分。

🚴

多账号并发用车

批量导入 Authorization，自动搜索可用账号；都在骑行中时最多等待 2 分钟到有账号还车后自动下单。

⏱

自动还车监控

下单开锁后后台持续监控 60 秒、每 3 秒检测进行中订单，立即还车并复核，防止「假性还车」扣费。

⭐

积分获取 / 兑换

查看各账号姓名、学校、手机号、信用积分与当前积分；支持定时运行、批量运行、自动兑换骑行卡。

🔐

完整管理后台

账号管理、订单信息、日志查看、积分获取、设置。手机号登录获取授权，批量认证免押金。

🔔

多渠道通知

Telegram、钉钉、企业微信、飞书、QQ 机器人、ntfy、Gotify、Webhook 等，事件独立开关与测试消息。

🔑

远程 API

X-API-Key 鉴权的下单与状态接口，配套手机端 Web App 可跨域调用，随处扫码用车。

Deploy

部署方式

五种方式任选，Windows 直接下载，Linux 源码运行，或 Docker 一键部署。

1 Windows 部署（推荐装 exe）

无需 Python，到 Releases 下载 7MA_v2.0.0.exe 双击运行，自动打开浏览器。

▶ 双击 exe → http://localhost:4321
2 Linux 从源码运行
pip install -r requirements.txt
python app.py   # 端口 4321
▶ http://服务器IP:4321
3 Docker 一键部署
docker run -d --name 7ma -p 4321:4321 \
  -v 7ma_config:/app/config -v 7ma_logs:/app/logs \
  --restart unless-stopped \
  zhacha222/7ma:v2.0.0
4 Docker Compose
docker compose up -d
镜像 zhacha222/7ma:v2.0.0 · 多平台 amd64/arm64/armv7
5 自行从源码构建镜像
docker build -t 7ma:v2.0.0 .
./docker/build-multiarch.sh 你的账号/7ma:v2.0.0
🔑 重置密码（各平台）

默认密码 password。忘记密码在服务端运行：

python reset_password.py 新密码
# Docker:
docker exec -it 7ma python reset_password.py 新密码
访问地址：浏览器打开 http://主机:4321，管理后台 http://主机:4321/admin。默认密码 password，登录后建议立即修改。
API

远程 API 调用

在「设置 → API 密钥」查看 / 生成 X-API-Key，调用时放入请求头。已开启跨域，手机端 / 任意页面均可调用。

GET /api/v1/status

查询服务状态

curl http://主机:4321/api/v1/status \
  -H "X-API-Key: 你的密钥"
响应: { "ok": true, "authorizations": 1, "time": "2026-09-01 12:00:00" }
POST /api/v1/order

远程下单

curl -X POST http://your/api/v1/order \
  -H "X-API-Key: 你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"bike_number":"123456"}'
响应: { "ok": true, "message":"下单", "unlock_result":"开锁成功", "is_success": true }
⚠️ 下单接口参数： bike_number（车辆编号）。失败时返回 ok:false 及 message 说明原因。
Mobile

手机端调用方法

配套手机 Web App 可直接扫码 / 手动用车，也支持打包安卓 APK。

01 网页端 App
  • 浏览器打开 http://主机:4321/app（或部署到静态空间）
  • 首次填写「服务地址」与「API 密钥」→ 点「测试连接」
  • 扫码用车：扫描二维码自动提取编号确认下单
  • 也支持「输入车辆编号」或粘贴二维码链接提取
  • 自动记录最近 20 条订单结果
02 安卓 APK
  • 在 Releases 下载 7MA.apk 安装
  • APK 需搭配 HTTPS 平台地址使用摄像头扫码
  • HTTP 下可用「相册 / 拍照 / 手动输入」兜底
手机访问主接口：POST /api/v1/order 携带 X-API-Key
浏览器 / WebView 调取摄像头需 HTTPS（或 localhost）。手机端下单逻辑与网页端完全一致，账号搜索、开锁、还车监控均由平台完成。
